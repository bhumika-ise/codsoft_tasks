# Tic Tac Toe AI 🎮

An AI-powered Tic Tac Toe game where the computer never loses using the Minimax algorithm.

## 💡 Features
- User vs AI gameplay
- Smart AI using Minimax Algorithm
- Console-based interface

## ▶️ How to Run
1. Install Python 
2. Open terminal
3. Run the command:

   python tic_tac_toe.py
